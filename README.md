# chinglai.design

Personal portfolio site for Ching Lai, a multidisciplinary product designer
with experience at [Uber](https://www.uber.com/),
[LeafLink](https://www.leaflink.com/), and [Zinio](https://www.zinio.com/).

Live at [chinglai.design](https://chinglai.design).

## Stack

- [Next.js](https://nextjs.org/) (App Router)
- TypeScript
- Deployed on [Vercel](https://vercel.com/)

## Development

```bash
npm install
npm run dev
```

The site runs at `localhost:3000`.
